# Magic Lantern Focus Peaking for Canon EOS 6D Mark II

An experimental Magic Lantern build for the **Canon EOS 6D Mark II running firmware 1.1.1**, with customizable LiveView focus peaking.

## Features

- Focus peaking overlay for LiveView.
- Adjustable peaking color, threshold, and filter bias.
- Peaking activates while the shutter button is half-pressed.
- Peaking pauses after a shot to give priority to saving the photo.

## Compatibility

This build is intended for the **Canon EOS 6D Mark II with firmware 1.1.1**. It has been tested on a camera, but it is experimental and may contain bugs.

**Do not install it on other camera models or firmware versions.**

## Installation

Download the ZIP file from the [Releases](../../releases) page and follow the Magic Lantern installation instructions for the EOS 6D Mark II. Use a dedicated SD card and keep a backup of your files.

## Notes

Focus peaking is a visual aid, not a guarantee that a subject is in focus. Results depend on the scene, lens, aperture, and selected threshold and filter settings.

This is an independent experimental build based on the Magic Lantern project. It is not an official Canon product or an official Magic Lantern release.
